# Fluxzero Homebrew Tap

Homebrew formula for the [Fluxzero CLI](https://github.com/fluxzero-io/fluxzero-cli).

## Install

```bash
brew install fluxzero-io/tap/fluxzero
```

The formula installs both commands:

```bash
fz version
fluxzero version
```

## Upgrade

```bash
brew update
brew upgrade fluxzero
```

## Uninstall

```bash
brew uninstall fluxzero
```

Formula updates are generated from immutable, tested artifacts published by the
[Fluxzero CLI](https://github.com/fluxzero-io/fluxzero-cli) release pipeline.
