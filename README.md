# Fluxzero Homebrew Tap

Install the [Fluxzero CLI](https://github.com/fluxzero-io/fluxzero-cli) with Homebrew and start building on [Fluxzero](https://fluxzero.io), the European cloud for AI-built apps.

[Get started](https://fluxzero.io/get-started) · [How it works](https://fluxzero.io/how-it-works) · [Docs](https://fluxzero.io/docs)

## Install

```bash
brew install fluxzero-io/tap/fluxzero
```

The formula installs both commands:

```bash
fz version
fluxzero version
```

## Upgrade

```bash
brew update
brew upgrade fluxzero
```

## Uninstall

```bash
brew uninstall fluxzero
```

Formula updates are generated from immutable, tested artifacts published by the
[Fluxzero CLI](https://github.com/fluxzero-io/fluxzero-cli) release pipeline.
